# TestTalon Community 3.0.0 — Features & Capabilities

[Documentation home](../README.md)

TestTalon Community is a free Playwright + TypeScript Web test automation framework. Community 3.0.0 focuses on Web automation. It is free to use for learning, evaluation, demonstrations and proofs of concept under the Community license (see `LICENSE.txt`).

| Category         | Community 3.0.0 Capabilities                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Web Automation   | Playwright + TypeScript browser tests, run in Chromium, Firefox and WebKit. Start with [Getting started](../start/setup.md)                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Branded Browsers | Google Chrome and Microsoft Edge, configured per project with Playwright's `channel` option. They are installed separately; see [Chrome and Edge](../configure/projects-and-environments.md#google-chrome-and-microsoft-edge)                                                                                                                                                                                                                                                                                                                                                |
| Configuration    | Multiple environments, environment profiles (`config/project-profiles/.env.<profile>`, selected with `metadata.envProfile`), multiple Playwright projects in one `playwright.config.ts` and a browser per project. Includes `dev`, the package-owned desktop and device-emulation browser projects, and `staging-chromium` and `qa-firefox`. The quick-start commands select the local demo explicitly. See the [quick start](../configure/projects-and-environments.md#quick-start-your-first-web-projects) and [Configuration and profiles](../configure/configuration-and-profiles.md) |
| Execution        | Parallel execution (two workers by default); headed on your machine and headless in CI; run one, several or all projects with `--project`; filter tests by tag or title with `--grep`; retries and timeouts you can change (by default no retries, 120 seconds per test and 10 seconds per assertion). See [Run your tests](../create-tests/writing-tests.md#run-your-tests)                                                                                                                                                                                                    |
| Architecture     | Object Repository (JSON selectors in `object-repositories/gui/`), WebActions (browser helpers such as waiting for a page, highlighting, clicking, filling, handling dialogs and downloads) and reusable common functions (framework helpers plus your own workflows). See [The recommended architecture](../create-tests/writing-tests.md#the-recommended-architecture) and [Browser helpers](../create-tests/web-actions.md)                                                                                                                                                 |
| Testing          | Assertions with Playwright `expect`; test data generation (random text, numbers, dates and accounts) and CSV, Excel, text and PDF data helpers; reusable test scenarios with tags and steps; fixtures from `@packages/web/lib/base-test` (`page`, `webActions` and automatic profile loading). See [Write your own tests](../create-tests/writing-tests.md) and [Test data](../create-tests/test-data.md)                                                                                                                                                                                       |
| Web Examples     | Approved Web examples under `tests/sample/webapp/functional/`: a bundled smoke test, `alerts-frame-windows.test.ts` (alerts, confirms, prompts, an iframe and a new tab), `widgets.test.ts` (accordion, tabs, slider, progress bar, date input and autocomplete), the Playwright website and TodoMVC examples, a HAR record-and-replay test, a PDF text test and Product Store login/purchase examples that require application configuration. See [The sample Web tests](../start/setup.md#the-sample-web-tests)                                                        |
| Debugging        | Screenshots, Playwright traces and video recording where the browser supports it, kept for failed tests in `logs/test-results/`. See [Investigate a failure](../results/reports-and-logs.md#investigate-a-failure)                                                                                                                                                                                                                                                                                                                                                    |
| Reporting        | Shared TestRunReporter for test/step logs, skip reasons and run totals; list reporter in the terminal, HTML reporter in `logs/html-report/` and JSON reporter in `logs/json-report.json`. See [Reports and logs](../results/reports-and-logs.md)                                                                                                                                                                                                                                                                                                                      |
| CI/CD            | A GitHub Actions workflow that runs the tests and saves the reports as downloadable artifacts. See [GitHub Actions](../run/github-actions.md)                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Documentation    | Guides for installation, configuration, environment profiles, Web testing, reporting, CI/CD and troubleshooting, listed in the [documentation index](../README.md) and [Troubleshooting](../help/troubleshooting.md)                                                                                                                                                                                                                                                                                                                                                       |
| Security         | Only Web features ship: no premium, internal or experimental modules. The environment profiles (`.env.local`, `.env.dev`, `.env.uat`, `.env.prodBeta`, `.env.prod`, `.env.qa`, `.env.staging`) ship exactly as they are in the platform repository: check each one and replace its values with your own. See [Secrets](../configure/configuration-and-profiles.md#secrets)                                                                                                                                                                                 |
