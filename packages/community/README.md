# Community package boundary

This package boundary contains the Community-safe product surface.

Allowed Community behavior:

- Web GUI automation
- basic Playwright reporting
- basic framework configuration
- sample web tests
- quick-start documentation and examples

Prohibited Community behavior under the edition boundary:

- API testing implementation
- mobile/Appium implementation
- database testing implementation
- ReportPortal/Allure/email commercial reporting
- TestCreator commercial AI implementation
