# Community participation

Thank you for your interest in TestTalon Community! We value feedback from developers and testers around the world, and we would love to hear how you use it.

TestTalon Community is source-available software under the TestTalon Free / Community Source Code License (see `LICENSE.txt`). It is not open-source software.

## How you can take part

- **Report a bug.** Open an issue with what you did, what you expected and what happened. Include your Node.js version, operating system and the exact error message.
- **Request a feature.** Open an issue and describe the problem you want to solve, not only the solution.
- **Give documentation feedback.** Tell us what was unclear, missing or wrong in the [Community documentation](core/docs/community/README.md).
- **Start a technical discussion.** Ask a question, share a use case or suggest an improvement.
- **Share general feedback.** Email [support@testtalon.com](mailto:support@testtalon.com).

Before you post, please remove passwords, tokens, internal addresses and personal data. Do not post code from a TestTalon Commercial edition.

Please follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Source-code contributions

We are **not accepting external source-code contributions at this stage**. Please do not open pull requests with code changes, and please do not fork this repository to prepare one. A pull request will be closed with a short note, and we will gladly continue the conversation in an issue instead. This keeps releases consistent and controlled; it is not a judgment of your idea or your code.

## Why this repository does not take code changes

TestTalon is developed in one private source repository. This public repository, like the Commercial edition, is generated from it at each release. Fixes and features therefore arrive here through a new release, and changes made directly in this repository would be replaced by the next one. If we adopt an idea from your feedback, we build it in the private source repository, and it reaches you in a later release.

## Security

Please report vulnerabilities privately to [support@testtalon.com](mailto:support@testtalon.com), not in a public issue.

Thank you for helping make TestTalon better!
